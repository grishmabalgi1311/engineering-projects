## How to read this collection

Each project explains what was built, personal/team contribution, available files, dependencies, and the limits of the evidence. Some mechanical projects contain reports and CAD images rather than software. Hardware sources are historical development files: no new flashing, motion test, or physical validation was performed for this publication.

The navigation comparison is from preserved server evidence; synthetic sensor results are explicitly labeled. Student frameworks, lab work, and collaborators are acknowledged. External SDKs, model weights, vendor toolchains, third-party papers, credentials, private records and raw recordings are excluded.

## Verification

Source integrity and syntax checks are recorded separately from execution. A successful syntax check does not establish that hardware, MATLAB toolboxes, simulator resources or course services are available. See each project before attempting a run.
