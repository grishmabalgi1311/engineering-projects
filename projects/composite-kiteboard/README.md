# Composite kiteboard analysis

Ansys ACP study of a carbon-epoxy sandwich structure with a polyurethane core, focusing on layup and structural response.

**Tools:** Ansys ACP / Static Structural / Composite layup / Meshing  
**Status:** Undergraduate team study

## Contribution and documented behavior

- Set up a composite sandwich model with carbon-epoxy plies and a polyurethane core.
- Examined ply orientations, stacking sequence and mesh setup under imposed bending/twisting boundary conditions.
- Interpreted equivalent-stress and deformation contours in a documented simulation study.
