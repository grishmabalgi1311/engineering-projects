# Adaptive recumbent bicycle

A recumbent bicycle design focused on seating ergonomics, chassis strength, and accessible steering and braking.

**Tools:** SolidWorks / Mechanical design / FEA

**Status:** Undergraduate design study

## Documented work

- Designed a recumbent bicycle concept for users with disabilities.
- Modeled the chassis in SolidWorks and considered structural load response.
- Developed steering and braking arrangements around user needs.

## Available evidence and files

The CV documents CAD and FEA work; original models, numerical results and a manufactured bicycle have not been recovered. No clinical or user-testing outcome is claimed.

This directory currently contains a CV-based project summary, not an executable code or CAD package. The original source artifacts have not been recovered for public curation. The private CV is not included. Illustrations on the portfolio are explanatory.
