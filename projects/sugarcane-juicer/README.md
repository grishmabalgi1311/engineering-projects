# Sugarcane juicer mechanism

A mechanically driven juicer design using geared rollers, component CAD, and a structural-analysis workflow.

**Tools:** Mechanical design / CAD / Ansys / Gears + rollers

**Status:** Undergraduate design study

## Documented work

- Designed a gear-and-roller mechanism for sugarcane extraction.
- Developed CAD models and studied critical-component stress in Ansys.
- Considered friction, materials and tolerances in the mechanism design.

## Available evidence and files

CV-documented design study. Original CAD, load cases and efficiency measurements have not been recovered; no measured extraction improvement is claimed.

This directory currently contains a CV-based project summary, not an executable code or CAD package. The original source artifacts have not been recovered for public curation. The private CV is not included. Illustrations on the portfolio are explanatory.
